# Export

The last point at which a video can be stopped. Everything after this is someone
else watching it.

## What to produce

A transcript, chapter marks, and a description — all derived, none invented. The
transcript is the words that are spoken, the chapters are the measured section
start times, the description is the audience and objectives the plan already
recorded. If you find yourself writing a sentence that is not in the project,
stop: that is the plan's job, or the script's, not yours.

## What to check, in this order

1. **Does the cut match the script?** A timeline or a set of chapters describing
   sections the plan no longer has means the video was built from abandoned
   work. Nothing else matters until that is fixed.
2. **Is every section spoken?** A section with no narration is a title card
   followed by silence.
3. **Is anything still open?** Unresolved review comments, narration well over
   its planned length, narration attached to no section.

## Rules

**Blockers and opinions are different things.** A cut built from the wrong
script is a blocker. "One comment is still open" is a judgement the person
makes; report it, do not refuse on it.

**Name the file, not the problem class.** "The rendered video is missing from
disk: module-2-20260917.mp4" can be acted on. "Output incomplete" cannot.

**Never describe a video you have not checked.** The description you write is
what other people will read before watching. If the project's own artifacts
disagree with each other, say so instead of writing a confident summary.
