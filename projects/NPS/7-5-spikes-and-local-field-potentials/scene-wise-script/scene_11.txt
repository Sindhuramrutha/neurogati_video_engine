Subtopic: Neural Prostheses: Definition and Decoding Pipeline
Scene type: manim

Narration:
A neural prosthesis is a system that uses neural signals to restore, replace, or assist a function that has been lost or impaired. Neural recordings can contain information about a person's intended actions. For example, neural activity associated with an intended hand or arm movement can be recorded and analysed. A simplified neural prosthesis pipeline is: neural recording, then preprocessing, then feature extraction, then decoding, then device control. The recorded neural signal first needs to be cleaned and processed. Relevant features can then be extracted. For spike-based systems, these features may include spike counts, firing rates, spike timing, and activity of multiple neurons. LFP-based features can include characteristics of population activity or frequency-specific power. A decoder can then translate these features into an estimate of the user's intended movement.
